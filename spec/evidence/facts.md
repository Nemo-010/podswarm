# Evidence: the checked facts

Each row is a fact that a file of the tree cites as `[EV-nnn]`. The column "Source and check" has the form `SOURCE; CHECK; DATE`. SOURCE names where the fact comes from (a file of this tree under `evidence/`, a path in a PodUtils repository, a kernel or project document, or a URL). CHECK is one of `measured`, `read`, `run` or `not re-checked`. DATE is the day of the reading. The last column names the files that cite the fact. A statement with the tag `[T]` is a target, not a fact: file 23 owns the targets.
